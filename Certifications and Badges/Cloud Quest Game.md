# Cloud Quest Game (AWS Cloud Quest)

This document showcases the completion of the Cloud Quest Game, an interactive, role-based learning experience designed to build foundational cloud computing skills through gamified challenges.
The game provides hands-on exposure to real-world cloud scenarios, allowing learners to solve problems using cloud services in a simulated environment.


## Skills Covered

- Understanding core cloud concepts (compute, storage, networking)
- Deploying and managing cloud resources
- Working with AWS services in practical scenarios
- Troubleshooting cloud-based applications
- Applying best practices for cloud architecture

## AWS Services Used

- Amazon EC2 (Virtual Servers)
- Amazon S3 (Storage)
- Amazon VPC (Networking)
- AWS Lambda (Serverless Computing)
- Amazon RDS (Databases)

## Game-Based Learning Experience

During the Cloud Quest Game, I completed various missions such as:

- Setting up virtual machines and web servers
- Configuring secure storage solutions
- Solving networking and connectivity challenges
- Deploying scalable cloud applications
- Fixing misconfigured cloud environments

## Example Challenges

- Launching and connecting to an EC2 instance
- Hosting a static website using S3
- Troubleshooting application downtime
- Configuring IAM roles and permissions

## Learning Outcomes

By completing this game, I was able to:

- Navigate and use the AWS Management Console
- Understand how cloud services work together
- Apply problem-solving skills in cloud environments
- Build and deploy simple cloud solutions
