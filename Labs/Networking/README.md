# Networking Labs

A collection of hands-on networking labs focused on building practical skills in cloud networking, infrastructure design, and network troubleshooting. These labs cover core concepts such as VPC configuration, subnetting, routing, security groups, and connectivity between resources in cloud environments (primarily AWS).

---

## 📌 Overview

This repository documents my practical networking exercises and labs completed as part of cloud computing and infrastructure training. Each lab demonstrates real-world networking scenarios using AWS and related tools.

The goal is to strengthen understanding of:
- Virtual Private Clouds (VPCs)
- Subnetting and IP addressing
- Route tables and internet gateways
- Security groups and network ACLs
- EC2 connectivity and troubleshooting
- Basic network design principles in cloud environments

---

## 🧪 Lab List

### 1. VPC Creation and Configuration
- Created a custom VPC in AWS
- Configured public and private subnets
- Attached an Internet Gateway
- Set up route tables for internet access

### 2. EC2 Instance Networking
- Launched EC2 instances in different subnets
- Configured security groups for SSH and HTTP access
- Verified connectivity between instances

### 3. Subnetting and IP Planning
- Designed CIDR blocks for efficient IP usage
- Created multiple subnets across availability zones
- Validated network segmentation

### 4. Route Tables and Internet Access
- Configured routing for public and private subnets
- Tested internet access from EC2 instances
- Implemented NAT gateway concepts (where applicable)

### 5. Security Groups and NACLs
- Defined inbound and outbound rules
- Compared Security Groups vs Network ACLs
- Tested access control behavior

### 6. Troubleshooting Connectivity Issues
- Diagnosed SSH and HTTP connectivity problems
- Used ping, traceroute, and AWS logs
- Resolved misconfigured routing and firewall rules
