# 🔐 Security Labs README

## 📌 Overview
This repository contains my hands-on **Security Labs**, where I practice real-world cybersecurity skills in a controlled cloud-based environment.

Through these labs, I gain practical experience in identifying vulnerabilities, securing cloud resources, and applying security best practices using AWS and Linux-based systems.

---

## 🎯 Objectives
In these labs, I aim to:

- Understand core cybersecurity principles  
- Practice securing cloud environments (AWS)  
- Identify and mitigate common security risks  
- Implement identity and access management (IAM)  
- Strengthen system and network security  
- Analyze and monitor security configurations  

---

## 🛠️ Tools & Technologies
- Vocareum Lab Environment  
- AWS Services (IAM, EC2, S3, Security Groups)  
- Linux Command Line (Bash)  
- Networking tools (ping, netstat, nmap)
