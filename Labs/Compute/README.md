# 💻 Compute Labs – AWS Practice

## 📌 Overview
This repository contains my hands-on **AWS Compute Labs**, where I practiced deploying, configuring, and managing compute resources in the cloud.

The labs focus on building practical skills using **Amazon EC2**, automation, and related services to simulate real-world cloud environments.

---

## 🎯 Objectives
Throughout these labs, I aimed to:

- Understand how to launch and configure EC2 instances  
- Practice secure access using SSH and key pairs  
- Configure web servers and automate setup using user data  
- Learn instance management and monitoring  
- Explore scalability concepts such as AMIs and Auto Scaling  

---

## 🛠️ Technologies Used

- **Amazon EC2**
- **AWS Management Console**
- **Linux (Amazon Linux)**
- **SSH (PuTTY / Terminal)**

---

## 📂 Lab Activities

### 🔹 Launching EC2 Instances
I launched EC2 instances with proper configurations, including:
- Instance type selection  
- Key pair creation and usage  
- Network and security group setup  

### 🔹 Connecting to Instances
I connected to Linux instances using:
- SSH (via PuTTY or terminal)  
- Session Manager (when applicable)  

### 🔹 Web Server Configuration
I configured a basic web server by:
- Installing packages  
- Running scripts using user data  
- Verifying web access via browser  

### 🔹 Creating AMIs
I created Amazon Machine Images (AMIs) to:
- Capture configured instances  
- Reuse setups for future deployments  
- Support scalability and automation  

### 🔹 Instance Management
I practiced:
- Starting and stopping instances  
- Monitoring performance  
- Managing instance states  
- Implemented Auto Scaling groups  
- Integrated load balancing
