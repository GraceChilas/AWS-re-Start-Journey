# 🗄️ Database Labs – AWS Practice

---

## 📌 Overview
This repository documents my hands-on **AWS Database Labs**, where I worked with both **NoSQL** and **relational databases** in the cloud.

The labs focus on building practical skills using:
- **Amazon DynamoDB (NoSQL)**
- **Amazon Aurora (MySQL-compatible relational database)**

---

## 🎯 Objectives
In these labs, I:

- Learned how to create and manage cloud databases  
- Practiced working with both structured and unstructured data  
- Understood key differences between **NoSQL and relational databases**  
- Performed CRUD operations (Create, Read, Update, Delete)  
- Connected applications/instances to databases  

---

## 🛠️ Tech Stack

- **Amazon DynamoDB**
- **Amazon RDS (Aurora MySQL)**
- **AWS Management Console**
- **SQL (MySQL syntax)**
- **Linux (EC2)**
- **MariaDB Client**

---

## 📂 Lab Breakdown

### 🔹 DynamoDB (NoSQL)

I worked with DynamoDB to:

- Create tables with partition and sort keys  
- Insert and manage items with flexible schemas  
- Perform queries and scans  
- Update existing records  
- Delete tables and data  

📌 **Key Concept:** Schema-less design allows each item to have different attributes.

---

### 🔹 Aurora (Relational Database)

I used Amazon Aurora to:

- Create a MySQL-compatible database instance  
- Configure connectivity within a VPC  
- Connect via an EC2 instance using the MariaDB client  
- Create tables using SQL  
- Insert and query structured data  

📌 **Key Concept:** Structured schema with defined relationships and SQL queries.

---

## 📘 Key Learnings

- Differences between **NoSQL vs Relational databases**
- Importance of **primary keys and indexing**
- How to securely connect compute resources to databases  
- Query optimization (Query vs Scan in DynamoDB)  
- Real-world database setup in cloud environments
