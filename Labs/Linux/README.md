# 🐧 Linux Labs README

## 📌 Overview
This repository contains my hands-on Linux labs, where I practice and demonstrate core Linux skills. These labs help me build a strong foundation in system administration, command-line usage, and troubleshooting.

Through these exercises, I gain practical experience working in Linux environments, which is essential for roles in cloud computing, DevOps, and cybersecurity.

## 🎯 Objectives
In these labs, I aim to:

- Understand the Linux file system structure  
- Use basic and advanced Linux commands  
- Manage files and directories  
- Control permissions and ownership  
- Monitor system performance  
- Work with processes and services  
- Practice networking and package management  

## 🛠️ Tools & Technologies
- Linux (Ubuntu / Amazon Linux / other distributions)  
- Bash (Command Line Interface)  
- SSH (Secure Shell)  
- Package managers (e.g., apt, yum)  

## 📂 Lab Structure
Each lab is organized into its own folder and typically includes:

- Step-by-step instructions  
- Commands used  
- Screenshots (where applicable)

### 🔐 Permissions & Ownership

- Understanding read, write, execute permissions
