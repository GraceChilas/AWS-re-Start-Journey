🤖 ## What Are Chatbots?

Chatbots are programs that simulate human conversation using Natural Language Processing (NLP). They are commonly used in:

- Customer service
- Virtual assistants
- Educational tools

---

🌟 ## Why AWS Lex?

AWS Lex enables developers to build conversational interfaces using voice and text. It powers services like Alexa and allows easy chatbot deployment.

---

🛠️ ## Part 1: Build a Basic Chatbot

## Step 1: Log in to AWS

- Open AWS Management Console
- Search for Amazon Lex

## Step 2: Create a Bot

- Click Create Bot

Choose:

- Language: English (ZA)
- Configuration: None
- Click Create
  
## Step 3: Create an Intent

- Go to Intents → Click Create Intent

Example name: S3Info

## Step 4: Add Utterances

Example:

- What is S3?
- Tell me about Amazon S3

## Step 5: Add Response

Amazon S3 is a cloud storage service that lets you store and retrieve any amount of data from anywhere.

## Step 6: Build & Test

- Save the intent
- Build the bot

Test using the chat window

✅ Result: A simple working chatbot

🎯 ## Part 2: Quiz Chatbot (Challenge)

🏢 ## Scenario

Client: Cloud Learners Inc.

Goal:

- Build an interactive quiz chatbot
- Provide feedback for answers
- Create an engaging learning experience

---

🧩 ## Step 1: Create Quiz Intent

Intent Name: S3Quiz

Sample Utterances:
- Start quiz
- Quiz me on S3
- I'm ready for the quiz

---

❓ ## Step 2: First Question

Question:

What does S3 stand for?

Options:

- A) Simple Storage Service
- B) Secure Server Storage
- C) Smart Storage System

---

🔀 ## Step 3: Branching Logic

✅ ## Correct Answer (A)

Correct! S3 stands for Simple Storage Service.

Would you like the next question?

❌ ## Incorrect Answers

Incorrect. The correct answer is Simple Storage Service.

Would you like to try the next question?

---

➡️ ## Step 4: Second Question

Question:

What is Amazon S3 mainly used for?

Options:

- A) Cloud storage
- B) Web hosting
- C) Cloud computing

Apply the same branching logic.

🧪 ## Step 5: Testing

Validate:
