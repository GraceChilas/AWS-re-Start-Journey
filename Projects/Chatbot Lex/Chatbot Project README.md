🤖 ## AWS Lex Chatbot Project – Interactive Quiz Bot

📌 ## Overview

This project demonstrates how to design and deploy an interactive chatbot using Amazon Lex.
The chatbot is capable of answering questions and conducting a quiz-based interaction using branching logic.

The solution was built as part of a hands-on cloud learning project to showcase AI-driven conversational interfaces.

---

🎯 ## Project Objectives

- Build a chatbot using Amazon Lex
- Implement intent-based conversation flows
- Design an interactive quiz system
- Apply branching logic for dynamic responses
- Demonstrate chatbot functionality through a live demo

---

🧠 ## Key Learning Outcomes

## Part 1: Chatbot Fundamentals

- Created and configured a Lex bot
- Built intents and mapped user utterances
- Designed simple automated responses

---

## Part 2: Advanced Chatbot (Quiz System)

- Developed a multi-step quiz chatbot
- Implemented conditional (branching) logic
- Improved user engagement with feedback loops

🧠 ## Quiz Design

- 🔹 Intent: S3Quiz
- 🔹 Sample Utterances

❓ ## Question 1

What does S3 stand for?

A) Simple Storage Service ✅
B) Secure Server Storage
C) Smart Storage System

✔ ## Correct Response
- Correct! S3 stands for Simple Storage Service.
- Would you like the next question?

❌ ## Incorrect Response
- Incorrect. The correct answer is Simple Storage Service.
- Would you like to try the next question?

---

🔀 ## Branching Logic

The chatbot:

- Evaluates user input (A, B, or C)
- Provides feedback based on correctness
- Guides users to the next step
